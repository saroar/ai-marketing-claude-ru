# SEO-аудит (Яндекс + Google)

## Назначение скила

Провести комплексный SEO-аудит сайта с акцентом на **Яндекс** (основной поисковик Рунета) и Google. Охватывает: on-page SEO, коммерческие факторы Яндекса, качество контента (E-E-A-T), технический SEO и стратегию контента.

Запускается командой `/market seo <url>`. Результат сохраняется в `SEO-AUDIT.md`.

---

## Выполнение

### Шаг 1: Запуск анализатора страниц

```bash
python3 ~/.claude/skills/market/scripts/analyze_page.py "<url>"
```

Если скрипт недоступен, продолжай без него и анализируй HTML через WebFetch вручную.

Также проверь:
- WebFetch на `/robots.txt`
- WebFetch на `/sitemap.xml`

### Шаг 2: Технический SEO

**Мета-теги и структура**
- Title тег: присутствует, оптимизирован (50-70 символов), содержит ключевое слово
- Meta description: присутствует, убедительна (150-200 символов)
- H1: один, уникальный, содержит основной запрос
- Иерархия H2-H6: логична
- Alt-тексты у изображений
- Canonical тег
- Robots.txt: не блокирует важные страницы
- Sitemap.xml: существует и доступен

**Для Яндекса — дополнительно:**
- Хлебные крошки (breadcrumbs) — повышают CTR в выдаче Яндекса
- Микроразметка schema.org — Яндекс активно использует для сниппетов
- Региональная привязка (если нужна): геотег, адрес в contacts, Яндекс.Вебмастер

### Шаг 3: Коммерческие факторы Яндекса

**Критически важно для коммерческих сайтов.** Яндекс ранжирует коммерческие сайты с учётом:

| Фактор | Проверка | Вес |
|--------|---------|-----|
| Цены на сайте | Указаны ли цены или диапазоны? | Высокий |
| Ассортимент | Достаточно полный для ниши? | Высокий |
| Контактная информация | Телефон, адрес, email, карта | Высокий |
| Условия доставки/работы | Прозрачные условия? | Средний |
| Отзывы на сайте | Реальные отзывы клиентов? | Средний |
| Онлайн-оплата | Есть ли возможность оплатить онлайн? | Средний |
| Гарантии и возврат | Условия возврата товара/услуги? | Средний |
| Сертификаты | Лицензии, сертификаты качества? | Низкий |

### Шаг 4: Качество и E-E-A-T

**Для главной и одной ключевой страницы:**
- Экспертность: есть ли авторы с опытом? Биографии специалистов?
- Авторитетность: упоминания в СМИ, рейтингах, партнёрства?
- Достоверность: ИНН/ОГРН, реальные контакты, юридическое лицо?
- Опыт: кейсы с конкретными цифрами, портфолио с результатами?

**Качество контента:**
- Глубина и полнота — отвечает ли страница на запрос исчерпывающе?
- Уникальность — не шаблонный ли текст?
- Актуальность — свежий ли контент?
- Читаемость — удобна ли структура для чтения?

### Шаг 5: Анализ ключевых слов

На основе содержимого страниц определи:
- Основные целевые запросы (явно присутствующие в заголовках и текстах)
- Естественность вхождений ключевых слов (нет ли переспама?)
- LSI-слова (тематически связанные) присутствуют?
- Коммерческие запросы: "купить", "цена", "заказать" — учтены?

**Ключевые отличия SEO для Яндекса vs Google:**
- Яндекс больше ценит текстовую релевантность для коммерческих запросов
- Поведенческие факторы (время на сайте, возврат) имеют большой вес в Яндексе
- Региональная привязка в Яндексе критичнее для локальных запросов
- Яндекс.ИКС (индекс качества сайта) — общий показатель доверия
